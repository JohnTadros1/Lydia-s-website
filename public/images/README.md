# Image provenance

`portfolio/` contains original JPEG photographs extracted from the Google Slides
presentation supplied by the owner:
https://docs.google.com/presentation/d/1iFFBQPyygs-H0GvaRIWCflWeG6z2dox5zJ8zE1vx5Ps/edit

Event names, themes, and guest counts come from that presentation. The hero uses
the engagement-party photograph. The gallery uses eight real portfolio photographs.

The three `wedding-*.webp` files were generated inspiration used during the initial
design draft; they are no longer displayed on the site.
